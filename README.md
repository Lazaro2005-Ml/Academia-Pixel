# Academia Pixel — servidor central y apps v8.2

Consultá **GUIA_EMPAQUETADO_CENTRAL.md**. Para ejecutar pruebas del backend:

`python -m pip install -r requirements.txt` y `python -m unittest discover -s tests -v`.

Los instaladores para usuarios se generan en Windows con los scripts `scripts/compilar_windows_central.ps1` y `scripts/compilar_android_central.ps1`, una vez publicado el servidor HTTPS.
